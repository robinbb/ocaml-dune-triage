# Batch 3 Bug Classification (Issues #11587 to #10653)

## Bugs Found

- **#11583** - packages depending on a toolchain-provided compiler can't cache the first time — Bug: shared cache misses occur on first build when using toolchains; second build does not benefit from the cache as expected.
- **#11574** - Cannot install dune using opam on Windows due to non-exist directory/file — Bug: dune compilation fails on Windows due to missing directory/file during bootstrap.
- **#11542** - `dune subst` inferred version is totally misleading and wrong — Bug/misfeature: `dune subst` uses `git describe` which produces misleading version strings that confuse users.
- **#11536** - pkgconf: unknown option -- personality — Bug: dune uses `--personality` flag not supported by older pkgconf versions, causing build failures.
- **#11523** - symlinks in directory targets don't go in shared cache — Bug: symlinks in directory targets prevent caching, which is incorrect behavior.
- **#11521** - `dune show targets` builds package dependencies before printing targets if a lockdir is present — Bug: `dune show targets` should not build dependencies, but does so when a lockdir is present.
- **#11518** - [BUG] dune build @check fails mysteriously with overlapping executables — Bug: `dune build @check` fails with confusing errors while `dune build @all` succeeds in the same project.
- **#11506** - error message on failing copy action is unclear — Bug: unclear/misleading error message when a copy action fails.
- **#11501** - dune doesn't reset DUNE_CACHE_ROOT inside cram tests — Bug: environment variable leakage causes spurious warnings inside cram tests.
- **#11500** - `@ocaml-index` is empty when not built from the root of a project — Bug: `@ocaml-index` alias produces no output when invoked from a subdirectory, unlike other aliases.
- **#11444** - ERROR while compiling dune.3.17.2 ($HOME/.cache/dune perms problem?) — Bug: dune compilation fails due to cache directory permissions issue.
- **#11440** - ctypes' `deps` field doesn't follow the dependency specification language — Bug: the `deps` field in ctypes doesn't work as documented; it doesn't follow the dependency specification language.
- **#11418** - dune-build-info is not working on flambda1 switch — Bug: `dune-build-info` fails with warning 58 error on Flambda1 switches; works on closure.
- **#11377** - dune build @doc doesn't update generated documentation properly — Bug: incremental documentation rebuild is broken; unchanged modules sometimes disappear from index.
- **#11303** - Too easy to reach MAX_PATH on windows — Bug: dune generates paths that are too long on Windows, hitting the MAX_PATH limit.
- **#11290** - `dune subst` issues with OCaml-CI — Bug/regression: `dune subst` fails since 3.17 in directories containing only an `.opam` file, which used to work in 3.16.1.
- **#11281** - Dune site (without plugins) forces `-linkall` — Bug/misfeature: `-linkall` is forced even when using dune sites without plugins, which is unnecessary and harmful.
- **#11276** - Package management should Ignore unused opam files when pinning — Bug: unused opam files with missing version info cause build failures when pinning.
- **#11229** - Dune developer preview: ocamllsp cannot read stdlib.cmi (corrupted compiled interface) — Bug: ocamllsp fails with corrupted compiled interface when using dune developer preview.
- **#11225** - dune-build-info: spurious `git describe` output instead of version string — Bug: `dune-build-info` returns git describe output instead of the version specified in `dune-project`.
- **#11190** - Internal error with `(env (_ (binaries (../tools/myrock.exe as coqc))))` — Bug: internal dependency cycle error when trying to override coqc binary via env stanza.
- **#11163** - dune cache — Bug concern: dune cache was enabled by default despite known issues; reporter asks whether prior cache bugs were actually fixed.
- **#11138** - Promotion and cross-compilation — Bug: file promotion with cross-compilation is non-deterministic; the wrong file may be promoted.
- **#11134** - Dune shows "Source files changed, restarting current build" for more than 30s — Bug: dune restarts build unnecessarily for 30+ seconds after file changes, causing confusing UX.
- **#11114** - Package management fails to read files when lock directory is ignored — Bug: `dune build` fails when the lock directory is listed in `.gitignore` or similar ignore files.
- **#11110** - Custom `libexec` sites install does not set executable bit — Bug: binaries installed to custom `libexec` sites lack the executable permission bit.
- **#11106** - Redundant dune version constraint — Bug: dune generates opam files with duplicate/redundant version constraints (e.g., `"dune" {>= "3.16" & >= "3.16.0"}`).
- **#11062** - dune should give priority to libraries in OPAM_SWITCH_PREFIX instead of ocamlc -where — Bug/misfeature: opam-installed packages are ignored in favor of system-wide packages, causing failures.
- **#11042** - Using (enabled_if %{read:...}) — Bug: documented feature `(enabled_if %{read:...})` doesn't work; produces error "%{read:..} isn't allowed in this position."
- **#11038** - `dune fmt` requires `ocamlc` to be in path but does not guarantee that this is the case — Bug: `dune fmt` with dev tools fails when `ocamlc` is not in PATH, even though dune should provide it.
- **#11037** - `dune fmt` and `dune build @fmt` build all the project's dependencies when a lockdir is present — Bug: formatting commands unnecessarily build all project dependencies when a lockdir exists.
- **#11017** - Coqdoc flags --with-header and --with-footer should imply a dependency on the argument files — Bug: changes to coqdoc header/footer files don't trigger documentation rebuild due to missing dependency tracking.
- **#11016** - Coq documentation generation fails with Coq in the workspace — Bug: coqdoc rules don't receive correct environment variables to locate the standard library when Coq is in the workspace.
- **#11014** - `coq.extraction` + `coq.theory` raises internal errors — Bug: combining `coq.extraction` and `coq.theory` stanzas produces unhelpful internal errors instead of a clear diagnostic.
- **#11012** - Coq cannot find the cmxs file for transitive ocaml dependencies — Bug: dune fails to place `.cmxs` files for transitive OCaml dependencies where Coq expects them.
- **#11010** - Dune crashes when editing a file in exec watch mode — Bug: dune crashes when editing a file during `exec --watch` mode.
- **#11002** - opam file generation could be made less error-prone — Bug/misfeature: dune silently generates incorrect opam files from typos like `:with_test` (should be `:with-test`), causing confusing downstream failures.
- **#10974** - "Shared cache miss" error while building project on different filesystem to cache directory — Bug: shared cache fails with EXDEV error when project and cache are on different filesystems.
- **#10970** - pkg: dune package management cannot build z3 — Bug: dune package management fails to build the z3 package.
- **#10954** - 'opam install dune' segfaults — Bug: installing dune via opam causes a segfault.
- **#10940** - Compilation of Dune 3.16.0 Fails on macOS M2 (ARM64) During `opam install` — Bug: dune 3.16.0 fails to compile on macOS ARM64.
- **#10896** - Using `@ocaml-index` with vendored libraries: `Error: Conflict between the following libraries` — Bug: `dune build @ocaml-index` fails with conflict errors when vendored libraries are present.
- **#10874** - macos: ld: warning: ignoring duplicate libraries: '-lunixbyt' — Bug: regression since #10763; duplicate library warnings appear on macOS.
- **#10872** - CRAM tests on windows — Bug: CRAM tests crash with internal error on Windows when `sh` is not found, instead of giving a clear error message.
- **#10806** - Formatting of multi-line / end of line / block strings — Bug/misfeature: `dune fmt` destroys multi-line string syntax by converting them to normal strings.
- **#10805** - [dune-configurator] PKG_CONFIG_PATH is ignored on macos — Bug: `PKG_CONFIG_PATH` environment variable is ignored on macOS in favor of brew paths.
- **#10799** - Dune 3.16 doesn't compile in OCaml 4.08/4.09 on Windows — Bug: dune 3.16 uses `Unix.ftruncate` which is unavailable on Windows before OCaml 4.10.
- **#10792** - Doc for building byte code incorrect — Bug: documentation for building bytecode executables is incorrect; `dune build foo.bc` doesn't work as documented.
- **#10764** - Dune crash with melange-webapi on Windows — Bug: dune crashes with internal error `Path.drop_prefix_exn` on Windows with melange-webapi.
- **#10732** - menhir option `--only-tokens` does not work — Bug: `--only-tokens` flag works with menhir 2.0 but not with 3.0; produces error about missing `.conflicts` file.
- **#10731** - Many noisy shared cache miss messages when using multiple filesystems — Bug: dune spams many cache miss error messages instead of showing a single warning when cache is on a different filesystem.
- **#10707** - Add correct lower bound to menhir — Bug/misfeature: dune assumes menhir supports `--infer-write-query` but doesn't enforce a minimum version, causing build failures with older menhir.
- **#10697** - Dynamic loading of packages: linking issues — Bug: dynamic loading of plugins with native dependencies (e.g., LLVM) fails with undefined symbol errors.
- **#10679** - `coq.extraction`: Adding a nested module to `extracted_modules` raises an internal error — Bug: internal error occurs when using nested modules in `extracted_modules` field.
- **#10678** - Dangling internal path when using virtual library — Bug: using a pinned virtual library (sexplib0) causes dangling internal path errors during compilation.
- **#10659** - Dynamic linking error via a Coq plugin or running an executable — Bug: dynamic linking errors occur when using Coq plugins, possibly due to dune's handling of linking.
- **#10653** - dune top --only-package pkg when pkg is also installed globally make the toplevel load both versions — Bug: `dune top` loads both local and globally-installed versions of the same package, causing conflicts.
